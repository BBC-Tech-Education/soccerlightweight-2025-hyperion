# PCB

Circuit board designs. Use one subfolder per board, e.g. `Main-Board/` or `Kicker-Board/`, containing:

- the design files (schematic and board)
- a **PDF of the schematic**
- the **Gerber `.zip`** for each version sent for manufacture, with the version in the name, e.g. `Main-Board-v2-gerbers.zip`
