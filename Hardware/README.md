# Hardware

| Folder | What goes in it |
| --- | --- |
| [`CAD/`](CAD) | Mechanical design: chassis, mounts, 3D-printed and laser-cut parts |
| [`PCB/`](PCB) | Circuit boards: schematics, board layouts, fabrication files |

**Tips**
- Commit an **export that anyone can open** alongside the source files: `.step` for CAD models, `.pdf` for schematics, and Gerber `.zip` files for boards that were sent for manufacture.
- Give each board or part its own subfolder, e.g. `PCB/Main-Board/` or `CAD/Kicker-Mount/`.
- GitHub refuses files over **100 MB**. If an export is that big, ask a coach.
