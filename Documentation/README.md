# Documentation

| Folder | What goes in it |
| --- | --- |
| [`Poster/`](Poster) | Your competition poster: the source file and an exported PDF |
| [`Technical-Description-Paper/`](Technical-Description-Paper) | Your Technical Description Paper (TDP): the source file and an exported PDF |
| [`Photos/`](Photos) | Robot photos and diagrams used in your README, poster or TDP |

**Tips**
- Always commit a **PDF export** next to the source file, so anyone can open it without the right app.
- Keep photos reasonably small (under ~5 MB each). Please don't commit videos. Upload them to the shared drive and link to them instead.
